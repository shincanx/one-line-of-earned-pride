A deterministic Python program that writes one quiet line of earned pride (165 characters, 1–240) to /output/entry.txt. The line: after a year of stumbling over every page, eight-year-old Milo finally reads the last line aloud without stopping — and his mother sets the book down like it was made of glass. A concrete scene with a real person, a long effort landing in one read, pride shown, never announced.

## Run it

```sh
python3 main.py
```
